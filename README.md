# 📰 Artbooms RSS

Feed RSS dinamico e automatico per [Artbooms.com](https://www.artbooms.com)  
Generato e aggiornato automaticamente tramite GitHub Actions + Render.

## ⚙️ Automazioni

- **persist_cache.yml** → aggiorna e salva la cache RSS ogni 15 minuti.
- **keepalive.yml** → mantiene attivi i workflow di GitHub in modo permanente, senza interventi manuali.

## 🌐 Feed pubblico

👉 [https://rss.artbooms.com/rss](https://rss.artbooms.com/rss)

Validato per Google News e compatibile con tutti i lettori RSS.

---

*(Questo feed viene aggiornato automaticamente anche se non si accede a GitHub o Render.)*
